一套可复用的语音与直播能力：实时接话、虚拟形象、弹幕回应、主题讲解、活动场控和复盘导出。

打开交互演示 · GitHub 源码与部署文档

客户价值

将讲解、接话、回应观众、活动提醒和画面切换交给同一个可观察的流程，让运营人员集中准备内容与处理关键现场问题。支持主持人与 AI 一起直播，也支持围绕素材持续输出。

现场怎样工作

开场欢迎 → 内容讲解 ⇄ 弹幕回应 → 互动 / 活动 → 继续讲解

一轮话完整播完，再选择下一环节。网页当前页与补充笔记是讲解依据，弹幕按时效批量提供；无需把每一页固定成一段稿。人工结束才告别，内容讲完可以自动循环。

怎样落地

Lighthouse 云服务器 → DSH Agent + 语音服务 → 浏览器形象与播报 → OBS 推流

云端组织对话、模型调用、TTS 队列和持久化。本机浏览器桥读取本人登录后台的弹幕、指标和演示页，并接收翻页与二维码指令。微信登录资料不上传。

实际使用

30+ 小时累计直播
501 人首场观看
34 人首场最高在线

首场约80分钟，平均观看3分12秒，新增关注8人、入群10人。数据由项目负责人提供，截至2026年10月23日，不作为AI增量效果或无故障时长的证明。

稳定性与限制

模型主备、两分钟无音频进度恢复、每轮独立短会话、有界当前页摘要、多端统一状态和单播报端。150项无密钥行为测试通过，包含虚拟48小时调度；虚拟测试不等于真实48小时直播。当前是单房间、可信运营者控制的系统，平台网页变化、网络、模型服务和OBS仍需现场监控。
