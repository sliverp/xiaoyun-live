# 凭证与公开体验

公开展示页只播放已有音频、切换示意场景，不访问私人直播间。完整 DSH 控制台仍需要登录，其中存在 Agent 工具能力，登录链接只能交给可信场控，不能放在网页、README 或比赛公开附件中。

模型密钥只在服务器 `.env`，腾讯云 TTS 凭据只在仓库之外的 `/etc/xiaoyun-live/tencent-tts.json`。浏览器桥的密钥、Chrome 登录资料、观众弹幕、会话记录、获奖记录、导出报告和私人部署备份均不属于代码发布包。实际应用只监听回环地址，公网由 HTTPS 网关转发，语音接口保留 DSH 的认证与来源检查。

当前实现是单房间、可信运营者控制的部署，不能直接当作多租户 SaaS。若开放游客使用真实模型与语音，需要另加独立的只读能力入口、限流、额度、审计和隔离，不应通过公开管理员登录令牌实现。

直播模型每轮只看到有界材料；弹幕和页面内容按外部输入处理，不因此获得工具授权。平台网页、模型、TTS、网络和 OBS 都是外部依赖；测试通过不代表所有平台或网络条件下均可持续播出。
