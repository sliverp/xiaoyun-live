# 小云弹幕口令抽奖

在直播导演台设置口令和参与秒数，然后点击顶部的「开始抽奖」。默认口令为“小云送大礼”，默认参与时间为 10 秒，可设置 5–60 秒。已开始 AI 直播即可排队，不要求刚好收到新的弹幕消息；抽奖排队或进行中时不能重复点击，也不能修改本轮口令。Mac 监听或专用 Chrome 断开时保留排队状态，连接恢复后再开始说明。没有实际收到匹配弹幕时不产生中奖者。

排队状态、等待条件与操作错误显示在导演台顶部。尚未收到近期视频号消息响应时提示连接状况，同时允许安排抽奖；不能把“没有新消息”当作拒绝排队的条件。

抽奖在当前完整口播及其所有音频片段播放完后开始，优先于普通弹幕回应、互动和翻页。若当前还在生成文案，先把该轮文案完整播完。开场欢迎仍先完成；手动请求结束直播会取消未完成的抽奖。最后一页已讲完时，已排队的抽奖先完成，再进入自动告别。

流程图中有三个抽奖节点：

1. **抽奖说明**：小云播报本轮具体奖品，说明完整输入口令的参与方式。该段播完才开始参与计时，之前的弹幕不参与。
2. **抽奖参与**：小云直接播报一小段互动，同时继续监听新弹幕。到截止时间冻结结果；互动音频较长时等整段播完才公布结果，不截断句子。
3. **开奖播报**：在参与窗口内首次接收到、正文去掉首尾空白后完整等于口令的那条弹幕中奖。程序按接收序号决定，不由模型选人或重抽。小云念出直播间完整显示昵称作为中奖 ID，并提醒扫描屏幕右下方二维码加入用户社群、联系工作人员领奖；后台保留平台标识、消息 ID 和接收时间供核对。没有匹配弹幕就明确播报没有中奖者，监听断开或直播间变化则取消本轮。

抽奖结果播完后继续原有主线。抽奖不增加讲解段数，不推进页码，也不重置互动间隔；参与口令弹幕不再作为普通聊天逐条复读，其他观众问题仍保留待回应。说明、参与和开奖期间禁止手动翻页，避免取消音频后失去计时起点。

`live-lottery.json` 以原子替换保存本轮、最近口令设置和历史记录。服务重启不会自动重抽；已经选出的中奖者保留，未完成轮次标记中断。JSON 直播数据导出同时记录抽奖时间、口令与结果。本场共两份奖品，第一次送一件文化衫，第二次送一个马年公仔。确定中奖者时即占用对应奖品；空结果或取消不占名额，可重试同一份奖品。奖品送完后禁止继续安排；可以在开播前追加奖品，已发记录与名额不会因重播或恢复而清空。不得把领取流程推给主持人。

普通弹幕队列最多保留最近100条；抽奖窗口独立保留第一条匹配口令的弹幕，后续成千上万条消息也不会把最早参与者挤出。直播报告保留完整采集记录。

实时语音和固定口播都使用腾讯云超自然大模型音色602003“爱小悠”。固定口播保持审核过的原文，预合成文件按内容哈希更新；语速仍由设置页控制。

验证：`node --test lib/live-lottery.test.mjs lib/live-lottery-flow.test.mjs lib/live-lifecycle.test.mjs lib/live-graph.test.mjs` 覆盖完整音频边界、限时匹配、接收顺序、重复点击、无人匹配、断连取消、重启保留结果和回到原流程。
